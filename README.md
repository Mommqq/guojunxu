# Guojun Xu Academic Homepage

Bilingual academic homepage for Guojun Xu, Ph.D. student at Wuhan University of Technology.

The page lists only published or formally accepted work:

- CVPR 2026: Distributed Image Compression with Multimodal Side Information at Extremely Low Bitrates
- IEEE Transactions on Multimedia: CODIC: Distributed Image Compression with Distortion–Perception Co-Optimization

Under-review and submitted manuscripts are intentionally excluded.

## Enable GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select branch **main** and folder **/(root)**, then click **Save**. The project site will be available at:

https://mommqq.github.io/guojunxu/
